Pense Bem App 🎮

Aplicativo inspirado no clássico brinquedo educativo brasileiro “Pense Bem”, recriado em versão digital utilizando React Native + Expo.

O projeto apresenta quizzes interativos baseados em bibliotecas temáticas, com foco em experiência nostálgica, interface gamificada e jogabilidade dinâmica.

✨ Funcionalidades
Sistema de perguntas e respostas
Bibliotecas temáticas
Pontuação automática
Ranking local
Timer de resposta
Bônus por velocidade
Respostas aleatórias
Feedback visual de acerto e erro
Interface inspirada no brinquedo original
